# Scoop Bucket

Bucket for [Scoop][scoop] containing manifests for installing tools and
applications that I have created.

## Usage

Add this bucket to Scoop and then install the package(s) you would like.

```
scoop bucket add markembling https://github.com/markembling/scoop-bucket
scoop install markembling/<package>
```

## Packages

The following packages are available in this bucket:

| Package | Description |
| --- | --- |
| `palette-picker` | Windows desktop app for selecting and managing colours. |
| `pal` | A command-line tool for working with colour palettes. |

See the [Scoop app listing for this bucket][listing]
for more info.
